# Reporting a security or privacy problem

Please don't open a public issue for a vulnerability or a privacy leak. Email [mike@lab44.dev](mailto:mike@lab44.dev?subject=drift%20security) with:

- what you found and where (the drift app, drift.lab44.dev or this repository)
- steps to reproduce it, and the drift version and device if it involves the app
- whether any personal data could be exposed

Only send the minimum detail needed to reproduce the problem. Don't include other people's data. You'll get a reply from a person. Fixes ship through App Store updates, and there is no bug bounty.

This repository contains no app source code. For general support, see [SUPPORT.md](SUPPORT.md).
